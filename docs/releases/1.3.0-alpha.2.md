# Teleno native 1.3.0-alpha.2

Release date: 2026-10-23. Channel: **experimental alpha**.

This native prerelease follows 1.3.0-alpha.1 and corrects two reproduced P2P
lifetime defects. Teleno queues owned block and transaction GossipSub payloads
onto its single SDK I/O runner, with finite pending-byte and message limits.
Stop retires the publication generation before the SDK shuts down. A narrow
patch to the pinned cpp-libp2p listener manager makes queued connection
callbacks acquire a weak owner before dispatch. Three native regressions cover
no-publication listener lifetime, concurrent publication/heartbeat and
publication/stop races.

The 2026-10-21 Fogata producer abort ended with glibc heap-corruption output,
but it left no readable core. The reproduced defects are plausible causes; the
exact instruction responsible for that historical abort is **not proven**.
The [validation summary](../validation/fogata-gossip-publication.md) records
the identified diagnostic builds, comparisons and remaining limits.

The correction preserves Koinos protocol bytes, consensus rules, full history
and block/receipt retention. A full-history mainnet producer, loaded chain
operation, and the broader low-resource issue-9 goals still require their own
qualification. This release does not activate a producer, rotate a key,
modify a database or update the Koinos One package/submodule.

Release assets should carry the clean source identity, normal Linux amd64
binary, native test report, build metadata and checksums. Verify their exact
commit and ELF hashes before installation. Start as an observer and follow the
[producer activation gate](../running-producer-node.md) before any mainnet use.
